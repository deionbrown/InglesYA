# English A1 Teacher Studio — Web Edition

## Local
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Online
Upload `app.py`, `lesson_data.json`, `requirements.txt`, and `assets/` to GitHub.
Then deploy the repository in Streamlit Community Cloud with `app.py` as the main file.

Includes Unit 1 with images, IPA, neural audio, dialogue, listening, speaking, quiz, review, and Light/Dark modes.
